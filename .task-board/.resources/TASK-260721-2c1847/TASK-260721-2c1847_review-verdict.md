## Required rework

1. Fix the Windows launcher generated by `agentsAttachmentsWrapperBody` (`tools/agents-infra/internal/infra/infra.go:945`). In CMD, `& exit /b %ERRORLEVEL%` is outside the `if` command and is expanded before the delegated command runs. It therefore exits unconditionally, makes the fallback unreachable, and can return a stale success result. Use a control flow that only exits after the selected launcher has run and returns that launcher's actual exit code. Add a Windows launcher-contract test covering sibling `.cmd`, sibling `.exe`, fallback, and failure propagation semantics.
