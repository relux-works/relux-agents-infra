# STORY-260830-1fcwnq: task-board-delivery-contract-defects

## Description
Defects in the task-board delivery contract observed while delivering agents-infra: states the board permits but cannot exit, and operations the contract requires but does not expose. Fixes land in the task-board tool repository, not in agents-infra.

## Scope
Defect reports and fixes for the task-board delivery contract. Fixes land in the task-board tool repository; this Story carries the reports, evidence and acceptance.

## Acceptance Criteria
Every filed defect names the permitted-but-unexitable state or the missing operation, carries reproduction evidence observed in this project, and states the contract the fix must satisfy. A defect is done only when the task-board release that fixes it is installed here and the original reproduction no longer reproduces.
