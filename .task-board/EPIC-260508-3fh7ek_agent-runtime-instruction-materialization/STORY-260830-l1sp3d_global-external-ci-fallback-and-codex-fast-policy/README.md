# global-external-ci-fallback

## Description
Publish the verified external-CI local-mirror fallback as a global workflow contract.

## Scope
Versioned global workflow instruction source, generated Claude and Codex surfaces, and setup/install verification.

## Acceptance Criteria
Global instructions narrowly permit exact local job reproduction only for verified externally unrepairable hosted-CI execution failures; code failures and repository protection remain blocking; setup installs matching generated instructions.
